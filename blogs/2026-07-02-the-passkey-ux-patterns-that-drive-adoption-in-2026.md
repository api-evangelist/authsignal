Authsignal outlines four UX patterns that determine whether users keep using passkeys: leveraging conditional mediation for autofill, using immediately available credentials for clear-intent flows, applying the WebAuthn Signal API to keep credential managers clean, and auto-upgrading password users to passkeys. These choices decide whether passkeys feel native or hard to discover.
